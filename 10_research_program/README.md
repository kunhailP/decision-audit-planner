# Research program: reliable evaluation after deployment shift

이 폴더의 목적은 지원서 문구를 꾸미는 것이 아니라, 하나의 연구질문을 독립적으로 소유하고 다음 연구로 확장할 수 있다는 증거를 만드는 것이다.

## Program question

> 학습·개발 환경을 벗어난 뒤 자동화 시스템의 성능을 검증해야 할 때, 제한된 인간 판단을 어떤 결정에 얼마나 사용해야 하는가?

## Flagship paper

**Decision-Specific Audit Planning for Retrieval under Distribution Shift**

- 단위: target queries와 query–document judgments
- 결정: recalibration과 policy selection
- 출력: act, collect more, abstain
- 방법론적 자산: decision loss, sequential certificate, cost accounting, prospective validation

## What this project should demonstrate

- 잘못 해석한 과거 결과를 스스로 교정하는 능력
- novelty를 최근접 문헌과 정확히 분리하는 능력
- estimand와 비용 단위를 먼저 고정하는 능력
- negative result를 method question으로 전환하는 능력
- 개발·확증 데이터를 분리하고 leakage를 통제하는 능력
- 다른 연구자가 재실행할 수 있는 artifact를 만드는 능력

이 여섯 가지가 연구 허브의 실제 가치이며, “MIT용”이라는 문구 자체는 과학적 기여가 아니다.

## Follow-on projects — only after the flagship

### P2 — Active allocation

random audit보다 disagreement/coverage-aware audit가 같은 pair budget에서 certificate를 더 빨리 만드는지 연구한다.

### P3 — Human–AI judgment integration

자동 relevance judge와 소량의 인간 판단을 결합하되 bias와 coverage를 보정한다.

### P4 — Cross-domain measurement

완성된 planner를 정치·법·과학 텍스트 측정에 외부 적용해, 모델선택과 보정의 human-label budget을 비교한다.

P2–P4는 현재 논문에 넣지 않는다. flagship의 method와 failure boundary가 확정된 뒤 독립 프로젝트로 연다.

## Portfolio evidence generated by the hub

- 한 편의 제출 가능한 방법론 논문
- 공개 코드와 reproducibility artifact
- negative-result와 deviation log
- 독립적인 research talk
- 후속 연구로 확장 가능한 problem formulation

연구 statement는 이 산출물이 실제로 존재한 뒤 작성한다.
